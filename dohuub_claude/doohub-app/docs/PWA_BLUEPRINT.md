# DoHuub Consumer PWA — Full Blueprint / Build Prompt

> **Purpose:** This document is a complete build prompt + map.  
> Use it to scaffold a **Progressive Web App (PWA)** in JavaScript (React + Vite).  
> Fill every `{{PLACEHOLDER}}` as you build. Do **not** invent random structure — follow this tree.

---

## 1. Product summary

| Field | Value |
|-------|--------|
| App name | DoHuub |
| Type | Progressive Web App (installable, offline-capable shell) |
| Audience | End customers (book services) |
| Stack | React + Vite + React Router + plain CSS modules (or CSS variables) |
| Backend | Existing DoHuub API (`EXPO_PUBLIC_API_URL` / Railway) |
| Motto / tagline | `{{APP_TAGLINE}}` e.g. “Lifestyle services, one hub” |

---

## 2. Libraries to install

Run from the new PWA project root:

```bash
# Create app
npm create vite@latest doohub-pwa -- --template react
cd doohub-pwa

# Core
npm install react-router-dom

# PWA
npm install vite-plugin-pwa workbox-window

# HTTP / state
npm install axios
npm install zustand

# Forms / validation (optional but recommended)
npm install react-hook-form zod @hookform/resolvers

# Dates
npm install date-fns

# Icons (pick ONE)
npm install lucide-react
# OR: npm install react-icons

# Images / lazy load (optional)
npm install react-lazy-load-image-component

# Env types (dev)
npm install -D @types/node
```

**Dev / build (already via Vite template):**

```bash
npm install -D vite @vitejs/plugin-react
```

**Do NOT install** (unless you explicitly decide later):

- Tailwind (unless you choose it — this blueprint uses CSS variables + CSS modules)
- Material UI / Chakra (keep UI custom and light)
- Redux (Zustand is enough)

```jsx
import { copy } from '../../constants/copy';

```

### Styles

- **Tokens / global** → `src/styles/*`  
- **Per screen / component** → `*.module.css` next to the file  
- **No inline style mess** except dynamic values (e.g. progress width)

```js
// services/api.js
```
